Supabase connection ഇതുവരെ ചേർത്തിട്ടില്ല

  3. Project Settings → API-ൽ നിന്ന് Project URL-ഉം anon public key-ഉം copy ചെയ്യുക.
  4. app.js-ന്റെ മുകളിലുള്ള CONFIG-ൽ അവ paste ചെയ്ത് save ചെയ്യുക. പേജ് reload ചെയ്യുക.
